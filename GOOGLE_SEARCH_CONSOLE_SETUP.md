# Google Search Console Setup Guide

This guide will help you submit your portfolio sitemap to Google Search Console for better indexing and visibility.

## Step 1: Verify Ownership

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click **"Add property"**
3. Choose **"URL prefix"** and enter `https://siddhantmanna.dev`
4. Select a verification method:
   - **HTML file** (easiest for Next.js)
   - **HTML tag** (recommended - no file needed)
   - **DNS record**
   - **Google Analytics** (if you've already set it up)

### Verification via HTML Tag (Recommended)

1. Copy the verification code provided by Google
2. Open `src/app/layout.tsx`
3. Add to the `metadata` object:
   ```typescript
   verification: {
     google: "your-google-verification-code-here",
   }
   ```
4. Deploy your changes
5. Return to Google Search Console and click "Verify"

## Step 2: Submit Your Sitemap

After verification is complete:

1. In Google Search Console, navigate to **"Sitemaps"** (left sidebar)
2. In the **"Add a sitemap"** field, enter:
   ```
   https://siddhantmanna.dev/sitemap.xml
   ```
3. Click **"Submit"**

Google will automatically crawl and index your sitemap.

## Step 3: Monitor Your Site's Performance

In Google Search Console, you can:

- **Coverage**: See which pages are indexed and any issues
- **Performance**: Monitor clicks, impressions, and CTR
- **Enhancements**: Check for issues with rich results, mobile usability, etc.
- **URL Inspection**: Debug specific pages

## Your Sitemap Location

Your sitemap is automatically generated by Next.js at:
- **URL**: `https://siddhantmanna.dev/sitemap.xml`
- **File**: `src/app/sitemap.ts`

The sitemap includes:
- All main sections (home, about, experience, projects, contact)
- Dynamic routes if any
- Priority and change frequency metadata

## Additional Tips

- **robots.txt**: Your `src/app/robots.ts` helps search engines understand what to crawl
- **Meta tags**: Open Graph tags help with social sharing and snippets
- **Structured data**: Your JSON-LD schema helps Google understand your content better
- **Mobile-friendly**: Your responsive design ensures good mobile indexing

## Troubleshooting

### Sitemap not found?
- Ensure your site is deployed and accessible
- Visit `https://siddhantmanna.dev/sitemap.xml` directly to verify

### Verification fails?
- Clear browser cache and try again
- Ensure the verification code is exactly as provided by Google
- Wait a few minutes and retry

### Pages not indexed?
- Check the "Coverage" report in Search Console
- Use the "Request Indexing" feature for specific URLs
- Ensure pages aren't blocked in robots.txt or with noindex tags
